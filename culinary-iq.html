In plain language

The React review screen saves only the locations the human selected.

Inputs, outputs and control flow

The handler reads the current bundle and selection, strips UI-only indices and sends typed locations to the API client. Success refreshes parent state and closes the review. Failure becomes an error message; finally clears saving state.

Design, integration and security

React state controls feedback. The server still owns validation and duplicate checks. Hiding or disabling a button alone cannot authorize writes. The callback runs after a successful response, so callback failure and write failure deserve different UI treatment.

Testing and verification

tests/test_assistant.py verifies backend confirmation and duplicate handling. The snapshot also passed frontend unit tests and a production build; this handler has no independently verified interaction-test result.

Potential improvements

Add a component test for failed saves and a separate outcome for post-save refresh failure.

  async function confirm() {
    if (!bundle || !selected.length) return;
    setSaving(true); setError(null);
    try {
      const result = await confirmAssistantEvidenceBundle(bundle.id, selected.map((item) => { const location = { ...item }; delete location._index; return location; }));
      await onSaved(result.restaurant_id, `${result.created_count} location${result.created_count === 1 ? "" : "s"} added after review.${result.duplicate_count ? ` ${result.duplicate_count} duplicate${result.duplicate_count === 1 ? " was" : "s were"} skipped.` : ""}`);
      onClose();
    } catch (reason) { setError(reason instanceof Error ? reason.message : "The reviewed locations could not be saved."); }
    finally { setSaving(false); }
  }

The database records messages and their supporting context so an operator can resume a conversation.

Inputs, outputs and control flow

The migration declares message identifiers, roles, content, metadata and a conversation foreign key. It creates a composite index for workspace-scoped chronological history.

Design, integration and security

A role CHECK rejects invalid roles. The foreign key can cascade deletes when foreign-key enforcement is enabled. The workspace index accelerates scoped reads but does not establish identity or authorize a request.

Testing and verification

tests/test_assistant.py covers creating, retrieving and archiving conversations against migrated SQLite fixtures.

Potential improvements

Measure query plans and enforce workspace consistency across parent and child rows where schema changes permit.

Overview and problem

Culinary IQ supports restaurant operations teams working with media, menus, and location information. Its assistant brings relevant application context and product guidance into the operator workflow and makes proposed updates reviewable.

Architecture and integrations

A Next.js, React, and TypeScript dashboard uses a Python and FastAPI backend. The assistant integrates OpenAI tool calling with contextual retrieval over a versioned product manual. SQLite persists conversations, tool audits, and pending evidence. Picker and an optional mapping provider support evidence collection through bounded integrations.

Implemented capabilities and safeguards

The workspace supports a persistent assistant, contextual tools, restaurant onboarding, menu and media workflows, and field-level evidence review. Pending evidence records its source and can be rejected. Approved updates pass through explicit confirmation. The current development identity is fixed, so external deployment requires authenticated workspace membership and tenant-isolation verification.

Engineering challenge

Assistant proposals combine user input, app records, and provider evidence. The workflow has to preserve field provenance and give the operator control over canonical updates.

Validation and roadmap

The sanitized snapshot passed 217 backend and eight frontend tests plus a Next.js production build. Authentication and tenant isolation remain deployment gates.

Development and portfolio preparation included AI assistance. Individual implementation authorship is not asserted.
